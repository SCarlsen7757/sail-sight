# Screenshots

Generated by `npm run screenshots` (Playwright, `SailSight.Web/e2e/screenshots/screenshots.spec.ts`) from the seeded E2E data. Do not edit by hand.

Layout: `<theme>/<viewport>/<page>.png`

- **Themes:** `light`, `dark`
- **Viewports:** `desktop` (1440×900), `mobile` (Pixel 7, 412×839)
- **Pages:** `login`, `home`, `sessions`, `session-detail`, `race-viewer`, `public-race`, `boats`, `courses`, `marks`, `teams`, `admin-users`, `upload`

## Regenerating

From `SailSight.Web`, with the SailSight dev stack stopped:

```bash
npm run e2e:up        # build and start the E2E stack
npm run seed          # fill it with the fixture data
npm run screenshots   # write the PNGs here
npm run e2e:down      # stop the stack and delete its database
```

Commit the changed PNGs with the UI change that caused them. CI also uploads a `screenshots` artifact on every PR for visual review; artifacts expire, so the committed files are the lasting copy.

Map tiles are replaced by flat, theme-coloured stubs so the images do not depend on a third-party tile service. Dates such as "Uploaded" reflect when the data was seeded, so those change on every run.
